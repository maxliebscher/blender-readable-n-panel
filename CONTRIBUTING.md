# Contributing and bug reports

This is an experimental fork, so focused reproduction reports are more useful than broad redesign proposals.

Include:

- exact build/version;
- Windows version and GPU;
- Blender UI scale;
- add-ons involved;
- exact steps;
- expected and observed behavior;
- whether the issue remains after disabling **Readable Labels**;
- a screenshot or short recording when relevant.

Use only disposable reproduction files. Remove confidential assets, scripts, paths, metadata, and personal information before attaching anything publicly.

For code changes, keep the minimal upstream readable-label proposal separate from experimental organizer features. Do not mix unrelated Blender formatting or generated-file changes into a patch.
