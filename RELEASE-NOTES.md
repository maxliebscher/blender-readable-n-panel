# v0.2.0-experimental

## Added

- Optional live search field above readable sidebar categories.
- Live filtering while typing, including a clear button.
- Filtering by category identifier, alias, or group.
- Persisted `Show Search Field` preference.
- Improved vertical spacing around group headings in the N-panel category gutter.

## Included from v0.1

- Optional readable labels with Vanilla fallback.
- Automatic/fixed width and row-height controls.
- Blender, alphabetical, and custom ordering.
- Favorites, aliases, groups, hidden categories, color tags, and safety guards.
- Portable profile and reset path.

## Important

This release is an unofficial Windows x64 test build based on Blender 5.3 Alpha. It is for evaluation only and must not be used on important files or in production.
